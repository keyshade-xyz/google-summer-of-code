# Google Summer of Code 2026 Guidelines and Project Ideas

Welcome to Keyshade’s Google Summer of Code (GSoC) 2026 program! 🎉
This document outlines our organization guidelines, contributor expectations, and proposed project ideas for students interested in working with Keyshade during GSoC 2026.

## About Keysahde
Keyshade is an open-source platform for secure secrets and configuration management, built to replace fragile .env workflows with a system that is auditable, access-controlled, and developer-friendly.

It provides versioned secret management, eliminates hard-coded credentials, enforces RBAC with audit logs, and integrates natively with cloud providers and CI/CD pipelines. The platform is secure by default, using modern cryptography and client-side decryption while remaining practical for day-to-day development.

## Contribution Prerequisites
Before applying we strongly encourage contrbutors to explore the platfrom in depth:
- **Main Repo**: [keyshade-xyz/keyshade](https://github.com/keyshade-xyz/keyshade)

Familiarity with these resources is essential for writing a strong proposal and making meaningful contributions.

## Guidelines
- Read the official [GSoC Contributor Guide](https://google.github.io/gsocguides/student/) published by the Google Summer of Code organizers.
- Go through the [GSoC 2026 Project Ideas List](/project-idea-2026) and carefully read our [Contribution Guidelines](https://github.com/keyshade-xyz/keyshade/blob/develop/CONTRIBUTING.md).
- Familiarize yourself with the [GSoC timeline](https://developers.google.com/open-source/gsoc/timeline), the application process, and the specific project you intend to apply for.
- Join our [Discord server](https://discord.gg/whqwPyRPsd) and introduce yourself in the `#general-chat` channel.
- Use the `#issues-discussion` forum for issue-related help, and direct all development-related questions to the `#contributors` channel on Discord.
- Start as early as possible and aim to submit a few meaningful code contributions to [Keyshade](https://github.com/keyshade-xyz/keyshade) before submitting your proposal.
- Other forms of contribution—such as helping on Discord, participating in GitHub issue discussions, or reviewing pull requests—are also highly encouraged.
- We value contributors who not only write code, but also actively contribute to and support the Keyshade community.
- Reach out to mentors early to discuss your proposed solution and technical approach before drafting your proposal.
- Share the first draft of your proposal as early as possible to receive feedback.
- Proposal drafts may be shared as text, Markdown, or Google Docs, provided they are easy to access and do not require downloads.
- Final proposals must be submitted through the Google Summer of Code website before the official deadline, after incorporating all reviews and feedback.
